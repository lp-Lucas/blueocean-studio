# Blue Ocean Studio

Editor de vídeo desktop da Blue Ocean com chat do Claude: preview em tempo real de um lado, agente editor do outro.

**Idealizado e desenvolvido por Lucas ([lp-Lucas](https://github.com/lp-Lucas)).** Veja [AUTORIA.md](AUTORIA.md).

## Instalar
Precisa de Node, ffmpeg, yt-dlp, Claude Code e Python com faster-whisper.

```
npm install
INSTALAR.bat
```

Como usar: [COMO USAR.md](COMO%20USAR.md).
